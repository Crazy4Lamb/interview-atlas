# 硅谷人物访谈录

七位人物的公开访谈、中文精读与来源档案。

[访问网站](https://crazy4lamb.github.io/interview-atlas/)

现收录 116 条去重资料，其中 68 篇有站内精读或导读、48 条为已核实的节目简介。支持按人物、角色、年份、主题和内容等级筛选，另附收录统计及 CSV 目录。统计范围不代表全部历史资料。

## 本地浏览

直接打开 docs/index.html。收藏、深浅色和字号偏好保存在当前浏览器，没有账号、广告或追踪功能。

## 部署与维护

这是纯静态网站，GitHub Pages 从 main 分支的 /docs 目录发布。内容位于 docs/data.js 与 docs/longreads.js，封面映射位于 docs/cover-data.js。目录见 docs/catalog.csv 与 docs/catalog.json。

## 内容与配图

本站为独立整理，与所收录人物及机构无隶属或代言关系。中文精读、导读与简介分别标明，均非完整逐字稿或完整翻译。每条资料附原始来源。

封面采用真实节目配图，并为缺图条目制作主题资料卡。原始节目图片及影音版权归原权利方；肖像与封面来源、署名和许可分别见 docs/portrait-sources.json 与 docs/cover-sources.json。代码及本站整理内容不改变第三方素材的权利。
